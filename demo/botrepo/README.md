# Demo bot repository

A tiny, fictional stand-in for the bot-engine repository that Funnel Studio reads
(`launches/<slug>/launch.yaml` + `funnel*.yaml` + `static/`). Everything here is invented:
the brand ("Northwind Academy"), the bots, the texts and the pictures (generated by
`scripts/make_demo_media.py`).

| Launch | What it is |
|---|---|
| `webinar` | One-off live webinar: confirm phone, welcome, channel reminders, paid-ticket offer, 3-question survey |
| `autowebinar` | Evergreen 3-day auto-webinar with a morning/evening time router, attendance gates, repeat for no-shows (call + SMS) |
| `leadmagnet` | Lead-magnet funnel: e-mail request, branching by buttons and by UTM source |

The Studio looks for this folder through `BOT_REPO_PATH` (default: this directory).
