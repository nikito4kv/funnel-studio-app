# Студия воронок

Визуальный редактор воронок чат-ботов (Telegram и MAX) и собственный движок, который эти воронки исполняет.
Основной README – на английском: [../README.md](../README.md). Здесь – краткий обзор по-русски и ссылки на
подробные документы (они написаны по ходу разработки, номера «этапов» в них – внутренняя нумерация).

## Что умеет

- **Редактор на холсте.** Собрать и поправить воронку мышью, выгрузить yaml, который читает движок
  бота (формат yaml-воронок bot-engine). Студия только читает репозиторий ботов, ничего в нём не меняет.
  Круговая проверка «yaml → граф → yaml» проходит на всех воронках демо-репозитория (`demo/botrepo`).
- **Версии.** Черновик и неизменяемые опубликованные версии, «было / стало» по смыслу, откат.
- **Симулятор.** Что и когда получит человек по расписанию, какая ветка выпадет, тест-прогон через тестового бота.
- **Простой режим** для постановщика и режим разработчика, превью «как в телефоне», навигация по большим воронкам.
- **Свой движок** (`runtime/`): опубликованная воронка начинает работать в Telegram и MAX без сборки образа
  и без перезапуска, таймеры лежат в Postgres, люди внутри воронки не теряются при публикации.
- **Импорт из Miro.** Фрейм по ссылке превращается в воронку с картинками; повторный импорт не стирает ручные правки.
- **Раздел «Боты».** Добавить бота по токену, имя, описание, аватар и команды прямо из Студии; токены хранятся зашифрованными.

## Быстрый старт

Нужны [uv](https://docs.astral.sh/uv/) (сам поставит Python 3.12) и Node.js.

```bash
uv sync
cd web && npm ci && npm run build && cd ..
uv run python -m studio.server          # http://127.0.0.1:8765
```

Данные (воронки, черновики, медиа) лежат в `data/` и в репозиторий не попадают. Другая папка – `--data <путь>` или
переменная `STUDIO_DATA`. Путь к репозиторию ботов – `BOT_REPO_PATH` (по умолчанию `demo/botrepo`).
Движок воронок дополнительно требует Postgres; запуск по шагам – в [runtime.md](runtime.md).
